# RedMagicEMU 0.1.0 Alpha

**Alpha 预览：指定 Guest 当前不能进入桌面，不适合日常使用。** 当前版本为 `0.1.0-alpha`。

## 当前阶段已完成

- 1A：应用身份与名称调整，保留来源及许可证；设备检查范围见 [进度](PROGRESS.md)。
- 1B：指定 NX809J Android 16 固件的构建指纹准入。指定 ZIP 已在独立测试包导入；指纹识别固件声明，不能证明来源或整个包的完整性，详见 [目标固件](TARGET_FIRMWARE.md)。
- 1C：单系统界面、底层单实例发布及启动准入；未实现的备份恢复不显示可用入口。暂存和固件提取期间取消、导入中断后的恢复提示及实例保留已有设备检查。

## 待后续版本与验收

- Guest 尚不能进入桌面，运行、显示、输入和音量等仍待后续版本验收；不得将系统自报启动完成视为桌面已显示。
- 准备期手动停止留待后续版本验证。真实设备空间耗尽、重复点击和历史多实例整理已按用户决定移出当前 1C 验收范围；现有底层保护保留。
- 导入进程恰在正常关闭标记写入后结束的边界，不提示中断，以避免误报主动取消或失败；该边界未作设备故障注入。备份恢复尚未实现。
- 已知 16 KB 页兼容警告仍未解决。更多设备结果和限制见 [进度](PROGRESS.md)。

## 验证

JDK 21 标准调试单元测试 187 项：155 项通过、32 项跳过、0 失败；标准及 clone 调试构建成功。独立测试包已在设备验证导入取消与中断提示，标准应用及其数据未覆盖。构建不等于原生组件重编译或 Guest 运行验收。
