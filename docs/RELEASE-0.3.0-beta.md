# RedMagicEMU 0.3.0 Beta

面向指定的 REDMAGIC NX809J 原厂 Android 16 / API 36 / ARM64 Guest，宿主型号不限。运行前请自行准备对应原厂固件。

## 本阶段

- Guest 可进入原厂桌面。已实测显示、触摸、文字输入、共享存储和 APK 安装。
- Guest 可经宿主桥联网、播放和录制音频。设备回归覆盖普通应用、远程网页和音视频场景。
- 单卡模拟基带支持虚拟短信和来电。普通振动经宿主 Android 振动接口运行，连续来电和计时器振动均通过复测。

## 已知限制

- 模拟基带覆盖虚拟短信和来电事件。
- 部分振动请求和超过 5 秒的请求可能导致振动桥断开。
- 手机可能显示 16 KB 页对齐兼容提示。详见[兼容矩阵](COMPATIBILITY.md)和[进度记录](PROGRESS.md)。

## 构建与安装

附件为标准 Debug APK。使用调试签名，覆盖安装要求签名一致。
