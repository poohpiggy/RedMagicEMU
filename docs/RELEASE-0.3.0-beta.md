# RedMagicEMU 0.3.0 Beta

面向指定的 REDMAGIC NX809J 原厂 Android 16 / API 36 / ARM64 Guest，宿主型号不受此限制。需要自行提供对应固件；本项目不分发原厂固件。

## 本阶段

- Guest 可启动进入原厂桌面，基本显示、触摸、文字输入、共享存储及 APK 安装已实测。
- Guest 可通过宿主桥联网、播放与录制音频；用户确认真实普通应用、远程网页及更多音视频场景可用，具体应用和格式未逐项记录。
- 单卡模拟基带支持虚拟短信与来电；普通振动通过宿主 Android 振动接口桥接，用户确认连续来电和计时器振动复测通过。

## 已知限制

- Beta 版本；断连恢复与长期稳定性暂未作为本阶段验收范围。兼容性不等同完整原厂硬件 HAL、DSP、RichTap 或硬件视频解码。
- 模拟基带不提供真实移动网络、IMS/VoLTE 或通话音频。GPS 定位未验证。
- Guest 应用身份与振动权限目前不能可信校验；部分未支持振动请求或超过 5 秒的请求可能导致桥断开。
- 手机可能显示 16 KB 页对齐兼容警告。更多证据和边界见 [兼容矩阵](COMPATIBILITY.md) 和 [进度记录](PROGRESS.md)。

## 构建与安装

附件为 standard Debug APK，使用本机构建的调试签名；与其他签名版本不保证可覆盖升级。原厂固件不包含在 APK 中。测试、构建和设备运行的覆盖范围应分别理解。
