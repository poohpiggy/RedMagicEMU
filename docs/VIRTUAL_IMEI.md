# 虚拟基带 IMEI

NX809J Android 16 ARM64 实例启用 AIDL 虚拟基带时，首次启动为该实例生成 15 位、Luhn 校验有效的合成号码；已有合法设置优先采用。号码保存在实例私有目录的 `virtual-imei`，后续启动复用；不读取宿主设备的 IMEI，也不通过服务命令行或日志传入号码。生成规则的 `00` 前缀只是本项目的合成约定，并不表示官方分配或可在真实蜂窝网络使用。

启动时从已保存的号码重建 Guest 内 `/data/vendor/radio/aemu-imei`，AIDL 的 `getDeviceIdentity` 与 `getImei` 返回同一号码和固定的合成软件版本 `01`；模拟基带断连时返回不可用。该软件版本并非读取自宿主硬件。若已有值损坏、与已配置值冲突，或者 Guest 中已有不同内容的同名文件，启动会报错而非自动更换号码。恢复时应先保全并核对实例内原值，避免让 Guest 身份意外变化。Guest 文件只用于传递合成号码，当前实现不保证只有基带服务能读它。

运行时副本可从 `virtual-imei` 重建，原厂 ROM 未修改。回退代码和自带 radio-service.jar 可恢复旧接口行为；回退不会自动删除已生成的实例文件。该功能已做电脑端测试和构建，尚需通过 Guest 实机验证 Android 框架是否显示号码。
