# 兼容矩阵

适用 Guest 为指定的 REDMAGIC NX809J 原厂 Android 16 / API 36 / ARM64 固件，宿主型号不限。

| 模块 | 实测 | 实现与使用说明 |
| --- | --- | --- |
| 相机 | 新实例通过前后摄切换、浏览器调用相机、原厂相机拍照及 DCIM 保存。0.6.0 恢复包通过前后摄回归 | 0.6.0 恢复了宿主 GL 桥、Guest GLES 和两份相机 HAL。曝光和 ISO 使用虚拟标称值。[相机兼容记录](../native/camerahal/NX809J_CAMERA_COMPAT.md) |
| 原厂主题和 ztecfg | 带 ztecfg 的新实例自动生成前景和三张息屏缓存。人物位置、唤醒动画、切换主题后恢复均正常 | 预计算遮罩用于 `IP_MC_W_CN` / `default_theme_64` 的指定壁纸。其他输入走原厂处理或返回空结果。[AOD 记录](AOD_THEME_CACHE.md) |
| 启动 | 一台设备全新导入及覆盖安装 0.2.0-alpha 后进入原厂桌面，核心进程在观察窗口内持续运行 | 从正常入口启动指定固件实例。[进度记录](PROGRESS.md) |
| 显示、触摸和文字输入 | 上滑解锁、进入设置、原厂键盘连续输入和选词均正常 | 显示和触摸经宿主桥接 |
| 界面语言 | 英文（美国）、英文（英国）、简体中文、繁体中文（台湾）、繁体中文（香港）均通过 311 条字符串的键、空值和占位符检查 | 旧 `en` 偏好迁移到 `en-US`。跟随系统时，其他语言统一使用英文（美国） |
| 存储和 APK 安装 | 共享文件双向读写、通过 RedMagicEMU 安装测试 APK，以及应用私有数据重启后读回通过 | 共享文件经宿主目录桥接，安装由 Guest 包管理器流式处理 |
| 实例容量显示 | 标准 Debug 包的实例设置页移除了容量滑块 | Guest 显示计算和取整后的容量。[进度记录](PROGRESS.md) |
| 传感器和指南针 | 原厂指南针显示动态航向、约 `42 µT` 的磁场及宿主经纬度 | 桥接加速度计、陀螺仪和磁力计。打开传感器桥接后，经纬度取自宿主授权的最后已知位置，宿主无海拔数据时显示 `--`。[N64 传感器诊断](../native/sensorshal/N64_DIAGNOSTICS.md) |
| 实例电池控制 | 模拟拔电和恢复供电时，设置页在 `65% · 交流电` 与 `65% · 未充电` 间即时更新 | 实例设置和运行时菜单均可跟随宿主或自定义。自定义值保存在当前 VM 的运行态，无运行态时默认 `100% + 交流电充电中` |
| 单卡模拟基带 | 通过宿主菜单发送虚拟短信和触发连续来电，Guest 可接听或拒接。飞行模式往返后短信和来电仍可用 | 单条短信限 70 个 UTF-16 单元。上一条待确认时会拒绝新短信。来电功能处理呼叫事件，不传送通话音频 |
| 虚拟 LTE 信号 | 状态栏有信号格，飞行模式往返后恢复 | EMU 固定生成 RSRP -95 dBm、RSRQ -10 dB、RSSNR 10 dB 和 level 4 |
| 虚拟 LTE 数据 | 0.6.0 恢复包通过设备测试 | 按实例启用。模拟基带提供 IPv4 bearer、`eth0`、网关、DNS、MTU 和 PDU session，联网经宿主 Internet |
| Guest 以太网 | 默认以太网处于 VALIDATED，HTTPS GET 通过证书验证并返回 204 | 使用宿主网络 |
| 开放虚拟 Wi-Fi | 标准 Debug 包通过状态栏、快捷面板、TRANSPORT_WIFI、DNS 和 HTTPS 检查 | 0.6.0 修复关 Wi-Fi 后仍可联网和闸门 FD 继承导致的 zygote 崩溃。绑定接口可能在未实际绑定时报告成功 |
| 音频播放和录音 | 合成音、来电铃声、短信通知、原厂录音与回放均通过设备测试 | 铃声准备失败或扫描结果不匹配时可重试。旧扫描超时且状态未知时在宿主下次重启后重试 |
| WebView 本地页面 | target SDK 28 及使用无标题栏主题的 target SDK 36 测试中，文字、JavaScript 和点击均正常 | target SDK 36 的旧探针可能被标题栏遮挡，纯原生对照也出现该问题 |
| 本地 MP4 | 系统播放器完整播放 640×360、24 fps、12 秒的 H.264/AAC 测试素材 | AVC 使用软件解码，显示和伴音经宿主桥接 |
| 振动 | 宿主响应两次 2 秒请求。最终安装版通过连续来电和计时器振动回归 | 普通振动通过宿主 Android 振动 API。部分振动请求或超过 5 秒的请求可能使桥断开 |

测试时间、设备条件、APK 摘要和运行时改动见[进度记录](PROGRESS.md)。
