# RedMagicEMU

RedMagicEMU एक अनौपचारिक, स्वतंत्र रूप से संचालित परियोजना है जो [AEmulator](https://github.com/uxazu/AEmulator) पर आधारित है; AEmulator स्वयं मूल [SENSES एमुलेटर](https://github.com/Istratii-tech/SENSES) पर आधारित है। यह REDMAGIC का आधिकारिक उत्पाद नहीं है और REDMAGIC से संबद्ध नहीं है।

परियोजना का लक्ष्य REDMAGIC NX809J के मूल Android 16 / API 36 / ARM64 फ़र्मवेयर को अतिथि के रूप में उपयोग करना है। यह सीमा अतिथि फ़र्मवेयर पर लागू होती है, होस्ट डिवाइस के मॉडल पर नहीं। इस फ़र्मवेयर का समर्थन और संचालन अभी किसी डिवाइस पर सत्यापित नहीं हुआ है; [प्रगति](../PROGRESS.md) और [बेसलाइन](../BASELINE.md) देखें।

## बिल्ड

Android परियोजना के लिए Android SDK 36 और NDK r28 आवश्यक हैं। बेसलाइन बिल्ड में JDK 21 का उपयोग हुआ था:

```shell
./gradlew :app:assembleStandardDebug
```

स्थानीय विकास में एप्लिकेशन ID `app.redmagicemu` है। Android इसे अपस्ट्रीम ऐप से अलग स्थापित करता है; निजी डेटा अपने आप स्थानांतरित नहीं होता। स्थानांतरण की विधि सत्यापित होने तक पुराना ऐप और उसका डेटा सुरक्षित रखें।

## योगदान और लाइसेंस

RedMagicEMU, [uxazu](https://github.com/uxazu) के AEmulator पर आधारित है, जो [मूल लेखक](https://t.me/istratii_tech1) के HTC Desire HD और HTC One M7 एमुलेटर से विकसित हुआ। उनके कार्य और मौजूदा कॉपीराइट तथा लाइसेंस सूचनाओं को मान्यता दी जाती है।
