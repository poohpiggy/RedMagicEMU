# RedMagicEMU

RedMagicEMU — неофіційний незалежно підтримуваний проєкт на основі [AEmulator](https://github.com/uxazu/AEmulator), який заснований на оригінальному [емуляторі SENSES](https://github.com/Istratii-tech/SENSES). Це не офіційний продукт REDMAGIC; проєкт не пов’язаний з REDMAGIC.

Проєкт орієнтований на оригінальну прошивку REDMAGIC NX809J з Android 16 / API 36 / ARM64 як гостьову систему. Обмеження стосується гостьової прошивки, а не моделі пристрою-хоста. Підтримку та роботу з цією прошивкою ще не перевірено на пристрої; див. [поступ](../PROGRESS.md) і [базовий стан](../BASELINE.md).

## Збирання

Для проєкту Android потрібні Android SDK 36 і NDK r28. Базове збирання виконано з JDK 21:

```shell
./gradlew :app:assembleStandardDebug
```

Для локальної розробки використовується ID застосунку `app.redmagicemu`. Android встановлює його окремо від початкового застосунку: приватні дані автоматично не переносяться. Зберігайте старий застосунок і його дані, доки спосіб перенесення не буде перевірено.
