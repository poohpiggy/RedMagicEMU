# RedMagicEMU

RedMagicEMU — неофициальный независимо поддерживаемый проект на основе [AEmulator](https://github.com/uxazu/AEmulator), который основан на оригинальном [эмуляторе SENSES](https://github.com/Istratii-tech/SENSES). Это не официальный продукт REDMAGIC; проект не связан с REDMAGIC.

Проект ориентирован на оригинальную прошивку REDMAGIC NX809J с Android 16 / API 36 / ARM64 в качестве гостевой системы. Ограничение относится к гостевой прошивке, а не к модели устройства-хоста. Поддержка и работа с этой прошивкой ещё не проверены на устройстве; см. [прогресс](../PROGRESS.md) и [базовое состояние](../BASELINE.md).

## Сборка

Для проекта Android нужны Android SDK 36 и NDK r28. Базовая сборка выполнена с JDK 21:

```shell
./gradlew :app:assembleStandardDebug
```

Для локальной разработки используется ID приложения `app.redmagicemu`. Android устанавливает его отдельно от исходного приложения: приватные данные автоматически не переносятся. Сохраните старое приложение и его данные до проверки способа переноса.
