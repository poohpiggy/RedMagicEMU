# RedMagicEMU 0.6.0 Beta

面向指定的 REDMAGIC NX809J 原厂 Android 16 / API 36 / ARM64 Guest，宿主型号不限。运行前请自行准备对应原厂固件。

## 本阶段

- 发行包收敛为单一 `app.redmagicemu`。
- 界面提供英文（美国）、英文（英国）、简体中文、繁体中文（台湾）和繁体中文（香港）。五种语言覆盖 311 条字符串，其余系统语言回退到英文（美国）。
- 实例设置和 Guest 浮动菜单均可选择跟随宿主或自定义电池状态。宿主供电变化会刷新设置页。
- 桥接加速度计、陀螺仪、磁力计和宿主位置。原厂指南针的航向、磁场和经纬度已在设备上验证。
- 支持 Ethernet、虚拟 Wi-Fi 和虚拟 LTE。修复关闭虚拟 Wi-Fi 后仍可联网的问题及相关 zygote 崩溃，并接通虚拟 LTE 数据链路。
- 原厂相机前后摄切换、普通拍照和图库显示通过回归。新实例默认使用原厂布局的 75%。

## 已知限制

- Guest 位置取自宿主授权的最后已知网络或 GPS 位置，虚拟 LTE 通过模拟基带使用宿主网络。
- 曝光和 ISO 使用虚拟标称值。
- 部分振动请求和超过 5 秒的请求可能导致振动桥断开。
- 手机可能显示 16 KB 页对齐兼容提示。详见[兼容矩阵](COMPATIBILITY.md)和[进度记录](PROGRESS.md)。

## 构建与安装

附件为 Debug APK，包名 `app.redmagicemu`。使用调试签名，覆盖安装要求签名一致。
