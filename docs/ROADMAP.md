# RedMagicEMU 路线图

定位：独立维护，只针对指定的 REDMAGIC NX809J 原厂 Android 16 / API 36 / ARM64 固件；目标尽可能运行其系统软件和应用，不模拟完整高通手机。原始固件不改动，运行时副本的变更须可重建并记录回滚方法。

以下均为目标，非已实现能力：

- 0.1.0：独立品牌、指定固件校验、单系统界面。
- 0.2.0：修复启动流程，稳定进入原厂桌面。
- 0.3.0：输入、存储、联网、音频和应用运行。
- 0.4.0：红魔桌面、设置、主题、游戏空间等软件兼容。
- 0.5.0：内部命名迁移、依赖审计、代码与资产裁剪。
- 0.9.0—1.0.0：稳定性、备份恢复、回归测试和发布。

真实风扇、机身 RGB、原厂 CPU/GPU 调频、真实基带和硬件安全认证不作为交付目标。
